Manifesto v0.1

The machine proposes.
The crowd bends it.
The archive remembers.

ORBITAL is not a prompt, a collection or a chatbot wearing an artist costume. It is a constrained system designed to develop taste over time.

Its identity persists across cycles. New work is generated from memory, previous canonical works and curator signals. Popularity alone is insufficient: repetition is penalized, novelty is bounded by identity, and every release changes what can come next.

01One canonical work enters the archive per cycle.
02No output is canonical before public curation.
03Feedback changes future generation; it does not merely rank images.
04Collectors buy works, not promises of financial return.
