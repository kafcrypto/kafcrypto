Methodology & data

Clear about what is live—and what is not.

Live exposure scanToken balances are queried from public Ethereum, Arbitrum and Optimism RPC endpoints for the initial governance token set.
Proposal sourcesSnapshot proposals are queried live where a supported protocol uses a mapped Snapshot space. Protocols without a public feed connected in this V0.1 are labeled unavailable.
PriorityPriority is a transparent heuristic using deadline proximity, proposal text signals and whether the scanned address has relevant exposure.
RecommendationsPersonalized recommendations are a Pro concept in this version. Demo recommendations are explicitly labeled as sample decision support, never live facts.
