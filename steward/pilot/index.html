SSteward Discovery Pilot
Wallet-first governance discovery

Discover what a wallet governs before deciding what it needs to do.

Steward scans wallet assets across supported EVM chains, maps recognized governance systems, checks voting power where possible, and then looks for relevant decisions.

No signup · no signature · public data only · missing coverage is labeled, never shown as zero
Discovery architecture

Not a hardcoded token list.

The scanner first discovers assets. A governance registry then enriches recognized assets with DAO, voting and proposal metadata. Anything not yet mapped stays visible as an unmapped asset instead of disappearing.

01

Discover assets

Query token holdings across Ethereum, Arbitrum, Optimism, Base, Gnosis and Polygon using public explorer APIs.

02

Map governance

Match token contracts to governance contexts such as RARI DAO, Uniswap, Arbitrum, Optimism, ENS, Aave and others.

03

Surface gaps

Unknown assets and unsupported governance systems are shown as coverage gaps. Steward never equates “not indexed” with zero.

Important: “all governance” is a discovery problem plus a governance-registry problem. This pilot makes discovery generic across supported chains; the registry can grow independently without rewriting the scanner.
